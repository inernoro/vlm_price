# 05｜来源与口径

## 官方来源

1. [OpenRouter Models API](https://openrouter.ai/api/v1/models)  
   2026-08-14 下载，共 411 个目录条目，其中 243 个声明支持 image 输入。`openrouter-model-pricing-snapshot.json` 保留最终 16 个模型及其价格、上下文、架构和供应商字段。

2. [OpenRouter 模型目录说明](https://openrouter.ai/docs/guides/overview/models)  
   说明 `pricing.prompt`、`pricing.completion`、`pricing.image` 等字段均以美元/单 token 或单单位给出，并说明模型可按价格、流行度、速度等排序。

3. [OpenRouter Usage Accounting](https://openrouter.ai/docs/cookbook/administration/usage-accounting)  
   说明 API 响应自动包含原生 tokenizer 的输入/输出 token 和 `usage.cost`。本报告实际费用取这个字段。

4. [OpenRouter 30 日排行榜数据 API](https://openrouter.ai/docs/api/api-reference/datasets/get-rankings-daily)  
   本次数据范围 2026-07-15～2026-08-13，快照时间 2026-08-14T08:03:05Z。它只返回每天 token 用量前 50 的公开模型及 other 汇总，不公开独立用户数。

5. [OpenRouter FAQ：价格和手续费](https://openrouter.ai/docs/faq)  
   推理价格转交上游、不加模型价差；购买 credits 收 5.5% 手续费，最低 $0.80。BYOK 是另一套费用规则，本次测试不是 BYOK。

6. [OpenRouter 多模态输入说明](https://openrouter.ai/docs/guides/overview/multimodal/overview)  
   支持图片 URL 与 base64 数据。本次采用 base64 PNG。

7. [阿里云百炼：视觉理解](https://help.aliyun.com/zh/model-studio/vision-model)  
   说明 Qwen3.7、Qwen3.6、Qwen3.5 与 Qwen3-VL 的视觉能力、结构化输出和图像分辨率规则。

8. [火山方舟](https://www.volcengine.com/docs/82379/?lang=zh) 与 [模型计费说明](https://www.volcengine.com/docs/82379/1544681?lang=zh)  
   说明视觉理解模型的接入入口，以及文字、图片转换为输入 token 后按输入/输出 token 计费的口径。

9. [智谱：GLM-4.6V](https://docs.bigmodel.cn/cn/guide/models/free/glm-4.6v-flash) 与 [GLM-5V Turbo](https://docs.bigmodel.cn/cn/guide/models/vlm/glm-5v-turbo)  
   说明视觉、文档、视频、工具调用与多模态 Coding 定位。

10. [Kimi API 概览](https://www.kimi.com/help/kimi-api/api-overview)  
    说明 Kimi K3 的原生视觉与长程任务定位。

11. [阶跃星辰：视觉理解模型](https://platform.stepfun.com/docs/zh/guides/models/vision) 与 [MiniMax 图片理解](https://platform.minimaxi.com/docs/token-plan/mcp-guide)  
    用于核对图片输入方式、模型能力和接入限制。

## 使用热度引用格式

Source: OpenRouter (openrouter.ai/rankings), as of 2026-08-14T08:03:05.065Z.

30 日 token 是使用热度代理，不是“使用人数”；不同供应商采用各自 tokenizer，跨模型 token 绝对量也不应被解读为完全同质的工作量。

## 报价口径

- 币种：OpenRouter 原始账单为 USD。
- 人民币：固定预算汇率 $1=¥7.20，只为帮助建立用户心智，不代表银行实时结算价。
- 图像：1024×1024、约 1MB；文件传输字节不是 VLM 的统一计费单位。
- 输出：极短 JSON。需要长描述、OCR 全文或推理过程时，费用会上升。
- 每张价：成功请求的 `usage.cost`；失败/重试另行列出。
- 批量价：简单线性外推，不含并发限流、失败重试、存储、网络、工程和人工审核。
- 推荐度：本次单图结果 + 价格 + 延迟 + 结构化输出 + 重试情况 + 任务是否性能过剩，不是通用权威排名。

## 可复核性

- `benchmark-results.csv` 可以重新计算 16 个模型的单张、1 千张、1 万张费用。
- `openrouter-model-pricing-snapshot.json` 可复核目录价格。
- `openrouter-usage-snapshot.json` 可复核 30 日 token 加总。
- `benchmark-mug-1024.png` 是统一输入图。
- API key、Authorization header、完整 base64 请求体和账户身份信息均未放入交付包。
