# 05｜来源与口径

## 当前价格来源

1. [OpenRouter Models API](https://openrouter.ai/api/v1/models)：每日读取监控模型、输入/输出价格与图片输入能力。
2. [OpenAI GPT-5.6 Luna](https://developers.openai.com/api/docs/models/gpt-5.6-luna)：核对当前 OpenAI 低成本档定位、图片输入和官方价格。
3. [火山方舟](https://www.volcengine.com/docs/82379/?lang=zh)：核对模型入口、视觉理解与计费说明。
4. [阿里云百炼视觉理解](https://help.aliyun.com/zh/model-studio/vision-model)：核对 Qwen 视觉模型能力和图片规则。
5. [智谱视觉模型文档](https://docs.bigmodel.cn/cn/guide/models/vlm/glm-5v-turbo)：核对 GLM-5V Turbo 定位。

## 历史实验来源

- OpenRouter API 响应中的 `usage.cost`、token、provider 与延迟；
- `assets/benchmark-mug-1024.png` 固定输入图；
- `data/benchmark-results.csv` 实验结果；
- `data/openrouter-model-pricing-snapshot.json` 实验日价格快照；
- `data/openrouter-usage-snapshot.json` 公开 30 日 token 热度快照。

## 报价口径

| 名称 | 定义 | 用途 |
|---|---|---|
| 当前目录预算 | 当前 token 单价 × 统一 token 假设 | 快速比较价格量级 |
| 实验室实付 | `usage.cost × 1000` | 证明真实请求成本 |
| 实验室下限/上限 | 正确结果中的最低/最高实付 | 给业务方建立边界 |
| 使用热度 | 公开 30 日 token 量 | 使用规模代理，不等于用户数 |

人民币采用固定预算汇率 $1=¥7.20。目录预算不含失败重试、存储、网络、工程和人工审核。

## 更新规则

- 当前目录预算每日自动刷新并保存核验时间。
- 实验结果按批次固化，不因目录更新而改写。
- 新模型只有在完成同图请求后才能从“待复测”改为“已实测”。
- 模型消失、字段无效或抓取失败时，自动任务失败并保留上一份可复核快照。

## 安全

API key、Authorization header、完整 base64 请求体和账户身份信息不进入仓库或交付包。
