# 03｜测试方法与原始结果

## 输入图片

- 文件：`benchmark-mug-1024.png`
- 尺寸：1024×1024
- 格式：8-bit RGB PNG
- 大小：1,025,019 bytes（0.978 MiB / 1.025 MB）
- 内容：浅灰背景上的一个红色陶瓷马克杯，杯把向右；无文字、无商标、无其他物体。
- 图片由 OpenAI 内置图像生成工具创建，只用于统一基准输入。

## 统一提示词

```text
Identify the single main object. Return ONLY compact JSON with keys object,
color, material, count, confidence. Use lowercase English values;
confidence is 0 to 1.
```

首轮参数：`temperature=0`，`max_tokens=100`。  
对输出被推理 token 挤占的 Gemini 3.7 Flash 与 GLM 5V Turbo，重试参数为 `max_tokens=500`、`reasoning.effort=minimal`、`reasoning.exclude=true`。NVIDIA 免费模型也做了同等重试。

## 账号级费用核对

测试前 OpenRouter key 的累计 usage 为 $0。测试后为 **$0.014937626**。本地保存的所有可计费 API 响应 `usage.cost` 求和也为 **$0.014937626**，两者完全一致。该总额包含：

- 11 个首轮有账单响应；
- Gemini 3.7 Flash 的首轮截断与成功重试；
- GLM 5V Turbo 的首轮无可见答案与成功重试；
- NVIDIA 两次失败没有返回可计费 usage。

## 局限

1. 每个模型只有一张标准商品图，不提供统计置信区间。
2. 延迟受地区、供应商、冷启动、排队和当天负载影响。
3. 自动路由可能在以后选到不同供应商和单价。
4. 目录价和模型可用性会变；JSON 快照只代表 2026-08-14。
5. “confidence” 是模型自报，不是校准概率；Mistral 的错误高置信正好说明不能直接相信它。
