# 03｜测试方法与原始结果

## 输入图片

- 文件：`assets/benchmark-mug-1024.png`
- 尺寸：1024×1024
- 格式：8-bit RGB PNG
- 大小：1,025,019 bytes（0.978 MiB / 1.025 MB）
- 内容：浅灰背景上的一个红色陶瓷马克杯，杯把向右；无文字、无商标、无其他物体。

## 提示词

第一组模型使用英文短提示：

```text
Identify the single main object. Return ONLY compact JSON with keys object,
color, material, count, confidence. Use lowercase English values;
confidence is 0 to 1.
```

新增模型使用等价中文提示：

```text
识别图片中的唯一主要物品。只返回紧凑 JSON，字段为 object、color、
material、count、confidence；值使用简体中文，confidence 为 0 到 1。
```

两者要求的字段、任务和判分标准一致。首轮参数为 `temperature=0`，输出上限为 100 或 300 token。对输出被 reasoning token 占满的 Qwen3.7 Flash 与 GLM-5V Turbo，将上限放宽后重试一次。

## 火山引擎 Seed 观察

Seed 2.1 Turbo 一次完成并返回可解析 JSON，物体、颜色、材质和数量全部正确。171 个输出 token 中有 145 个 reasoning token，因此它的短答案成本主要不是可见文字，而是内部推理。

本次延迟 10.11 秒、费用 $0.0011195。对于普通分类，关闭或压缩思考过程更合理；对于图表、页面、复杂关系和工具调用，额外推理可能更有价值。OpenRouter 供应商显示为 `Seed`，直连火山方舟时仍应重新记录 token、价格与延迟，不能直接沿用本次数字。

## 重试为什么必须计入

### Qwen3.7 Flash

- 首轮：输入 1074、输出 301，其中 reasoning 300；无可见答案，费用 $0.00007135。
- 重试：输入 1074、输出 595，其中 reasoning 541；返回正确 JSON，费用 $0.00010957。

### GLM-5V Turbo

- 首轮：输入 1339、输出 100，全部被推理占用；无可见答案，费用 $0.0020068。
- 重试：输入 1339、输出 159，其中 reasoning 123；返回正确 JSON，费用 $0.0022428。

“成功请求单价”便于横向比较，但生产预算还应计算失败率、重试率和兜底模型成本。

## 局限

1. 每个模型只有一张标准商品图，不提供统计置信区间。
2. 中文与英文提示语义等价，但模型对语言的偏好可能造成轻微差异。
3. 延迟受供应商、冷启动、排队和当天负载影响。
4. 自动路由可能在以后选到不同供应商和单价。
5. 目录价和模型可用性会变化；快照只代表 2026-08-14。
6. `confidence` 是模型自报，不是校准概率。
