# 02｜交叉验算

## 通用公式

```text
单张美元 = 输入 token × 输入单价（美元/token）
         + 输出 token × 输出单价（美元/token）
         + 按图/按请求附加费（本次所选模型均为 0）

单张人民币 = 单张美元 × 7.20
N 张预算 = 单张人民币 × N
含购入 credits 手续费的规模预算 ≈ N 张预算 × 1.055
```

OpenRouter 模型目录的 `pricing.prompt` 与 `pricing.completion` 是**每个 token** 的美元价；报价页面常展示为每 1M token。API 的 `usage.cost` 是最终账单，优先级高于根据目录价自行估算。

### 路由价格的坑

Llama 4 Maverick 的目录起价是输入 $0.20/M、输出 $0.696/M，但本次 OpenRouter 自动路由到 Novita，账单明细反推为 $0.27/M、$0.85/M。因此：

```text
按目录起价估：2512×0.20/M + 35×0.696/M = $0.000526760
实际账单：    2512×0.27/M + 35×0.85/M  = $0.000707990
差额：$0.000181230，即实际高约 34.4%
```

生产环境如果必须锁成本，应限制供应商或在请求后记录 `usage.cost` 和 `provider`，不要只保存 token 数。

## 为什么 1MB 不进入公式

这张 PNG 是 1,025,019 bytes。发送 API 时 base64 会增大传输体积，但供应商返回的计费依据仍是视觉/输入 token，而不是上传字节：相同 1024×1024 图改成更小的 JPEG，通常只是带宽下降；除非压缩损伤导致识别质量变化，否则 token 成本不会按文件 MB 成比例下降。

真正降本顺序通常是：

1. 选更便宜且通过你自有数据集的模型。
2. 把分辨率降到仍能看清目标/OCR 的最低值。
3. 约束输出为短 JSON，禁止解释。
4. 批量离线任务使用 batch 变体（若模型支持，目录通常是 50% 价格）。
5. 为失败设置有限重试与兜底模型，避免无限烧钱。
